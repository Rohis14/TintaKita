# TintaKita — Sistem Informasi Digital Printing & Sablon Custom

Aplikasi pemesanan layanan percetakan dan pemantauan progres produksi berbasis client-server dengan pembagian hak akses (Pelanggan, Operator, Admin).

## Tech Stack
- **Frontend:** Flutter (Mobile & Web)
- **Backend:** Node.js, Express.js, JWT Authentication
- **Database:** PostgreSQL (Aiven Cloud)
- **Media Storage:** Cloudinary
- **Deployment:** Vercel / Netlify

- \main\ : Kode utama siap rilis
- \ackend\ : Pengembangan REST API Express.js & integrasi database
- \lutter\ : Pengembangan antarmuka pengguna multi-role
